# Feedback & Model Revision

## Feedback must be interpreted

**Core idea**  
Corrective information changes learning only when the learner interprets the discrepancy and updates the relevant knowledge, strategy, or action.

**When it matters**  
The learner sees the correct answer yet repeats the same error, fixes the output without understanding the cause, or treats feedback as a local patch.

**Teaching consequence**  
Make the informative discrepancy explicit: what was assumed, what evidence contradicts it, and what should change. Then let the learner act again using the revised interpretation.

## Conflict does not automatically revise a model

**Core idea**  
Evidence that contradicts an existing model can be ignored, reinterpreted, or absorbed without changing the underlying representation.

**When it matters**  
The learner explains away counterexamples, treats anomalies as exceptions, or accepts a correction verbally while keeping the same explanatory structure.

**Teaching consequence**  
Surface the competing explanations and ask what each predicts. Use evidence that discriminates between them rather than assuming surprise alone creates conceptual change.

## Old and new models may coexist

**Core idea**  
A newer model can be learned without fully eliminating an older one. Context, cues, or time pressure may reactivate the old model.

**When it matters**  
The learner gives the correct explanation in one setting but reliably returns to the older misconception in another.

**Teaching consequence**  
Practice selecting the newer model across varied contexts, contrast the cues that trigger each model, and test which representation is actually being used rather than reteaching from zero.
